# Tsalis Ainur Rofi — Static Portfolio

A minimalist, bilingual, privacy-conscious static portfolio website.

## Files

- `index.html` — main website
- `style.css` — responsive styling
- `script.js` — language toggle, project filtering, mobile navigation, project modal
- `assets/profile.jpg` — profile photo
- `assets/projects/` — place project screenshots here when ready

## Before publishing

1. Review every public text.
2. Add project screenshots only after removing private information.
3. Do not upload NIK, NIM, home address, phone number, passwords, API keys, tokens, private certificates, or other people's personal data.
4. Keep professional contact through LinkedIn unless you deliberately choose another public contact channel.
5. Replace project descriptions with exact details/results when you have the final screenshots and project information.

## Google Cloud Storage

The website is intentionally static and can be uploaded as a group of files. Make sure `index.html` remains the website entry point.

For the class assignment, configure the bucket and public object access according to the lecturer's instructions. Public access means anything placed in the bucket should be treated as potentially accessible to other people.
